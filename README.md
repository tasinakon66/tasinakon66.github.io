# TRA Studio website

Static site: plain HTML, CSS and JavaScript. No build step.

- `index.html`: all the page content (game text, links, emails)
- `style.css`: colours, fonts and layout
- `main.js`: animations (GSAP)
- `assets/`: game images, favicon, share image
- `fonts/` and `vendor/`: self-hosted fonts and GSAP, so the site does not depend on outside servers

## Edit something
Open `index.html` in VS Code, change the text, save, then commit and push in GitHub Desktop.
The live site updates about a minute later.

## Hosted on
GitHub Pages, from the `main` branch, root folder.
